1. Chunking

Break your source text into smaller pieces. This helps the AI find specific information more accurately.

2. Vector Embedding

Now, we transform each text chunk into a high-dimensional vector (a list of numbers) representing its meaning.

3. Store in Vector Database

In a real RAG app, these vectors go into a database like Pinecone or Milvus. Here, we'll use your browser's Local Storage.

Ready to store chunks and vectors...

4. User Query

What would you like to ask the AI about the document you just processed?

5. Semantic Retrieval

The system finds the Top N chunks whose vectors are mathematically closest to your query's vector.

6. System Prompt

This is the final prompt that gets sent to the LLM. It combines your query with the retrieved context.

7. Grounded Answer

The AI answers based on the retrieved facts, not just its training data.
